# Справка к ПР №8: рентгеновский контроль алюминиевой продукции

## 1. Продукция предприятия и аналог с повышенными допусками

**Что выпускает предприятие (в рамках проекта):**
- Цилиндрические слитки (заготовки для прессования), одна из основных форм поставки алюминиевых сплавов для дальнейшего передела, продукт с высокой добавленной стоимостью.
- Литейные сплавы (чушки, слитки).
- Плоские слитки, катанка.

**Почему рентген не встроен изначально** Для цилиндрических слитков внутренние дефекты (пористость, плены, включения) обычно ловят ультразвуком и макро/микроанализом; микроструктуру цилиндрических слитков предприятие уже анализирует нейросетями. Рентген естественнее для **отливок** и контроля образцов/сечений.

**Аналог с повышенными допусками (для MVP и первого пилота):**

| Критерий | Слитки для прессования (целевой продукт) | Аналог: отливки общего назначения / литейные чушки |
|---|---|---|
| Требования к внутренним дефектам | жесткие (дальше экструзия/ковка) | мягче: допускается пористость по классу ASTM E155 / ГОСТ |
| Размер недопустимого дефекта | малый | крупнее, проще детектировать |
| Цена ошибки | высокая (рекламация, порча передела) | ниже |
| Доступность данных | закрытые | открытые датасеты (GDXray, рентген алюминиевых колес) |

**Вывод для MVP:** начинать с продукции с повышенными допусками: дефекты крупнее, проще разметка.

## 2. Рентгеновская дефектоскопия: сколько проекций

- **Простая деталь / образец:** 1 проекция.
- **Сложная отливка (колесо, корпус):** несколько ракурсов, система наклоняет источник и детектор. Пример: ZEISS OMNIA GC 220-180: наклон источника и детектора до ±45° и неограниченное число углов съемки. HEITEC HeiDetect Wheel: несколько зон колеса проверяются из одной позиции большим детектором, чтобы сократить число перестановок.

- **Компьютерная томография (КТ):** сотни проекций, 3D-реконструкция. Быстрое сканирование низкого разрешения = 12 с, детальное = 5 мин.

**Что значит для MVP:** сеть должна работать на одной проекции, а итоговое решение годно/брак агрегировать по всем проекциям детали (деталь брак, если брак хотя бы на одной).

## 3. Градиент: как по нему видно повреждение

- **Пространственный градиент** (изменение яркости между соседними пикселями). Однородный металл даёт низкий градиент. Трещина даёт тонкую линию высокого градиента, пора даёт кольцо на границе пятна, включение даёт темное пятно с кольцом. Границу детали градиент подсвечивает сильнее всего, ее нужно маскировать.
- **Операторы:** Собель, Лаплас, Кэнни, разность гауссианов; перед градиентом нужно сглаживание, иначе шум детектора дает ложные срабатывания.
- **Временной градиент (видео/поток):** разность кадров при движении детали по конвейеру; помогает отличить артефакт детектора (пятно стоит на месте, пока деталь движется) от настоящего дефекта (он перемещается вместе с деталью) и отследить один дефект в нескольких кадрах.
- **В MVP:** градиент подан сети как второй канал (панель 2 на рисунке результата).

## 4. Поточный контроль: требования к скорости

| Показатель | Значение | Источник |
|---|---|---|
| Время цикла 2D-рентген на одну проекцию (серийное литьё) | 3–3,5 с | ZEISS OMNIA GC 220-180 |
| Простой между сканами | ≤ 6 с | ZEISS BOSELLO OMNIA |
| Требование к обработке изображения нейросетью | < 2 с на изображение, на обычном промышленном ПК без дискретной GPU | препринт Hengst SE, 2025 (не рецензирован) |
| Скорость инференса исследовательской модели для колёс | 39 кадров/с | Sensors, 2025 |
| Требование к полноте | 100 % деталей (inline), без участия оператора | ZEISS |

**Целевое требование для проекта (предложение):** обработка проекции ≤ 1–2 с на CPU/скромной GPU; время цикла не должно быть узким местом линии. Мой MVP на CPU обрабатывает изображение 256×256 за единицы секунд, это нужно ускорять свёрточной сетью.

## 5. Примеры из Китая

Ниже примеры из открытых источников: патенты и исследования китайских групп.

- **Автоматическое обнаружение дефектов в литых колёсных дисках по рентгену:** проблемы ручного контроля описаны так: усталость, нестабильные критерии, субъективность; на большинстве линий всё ещё ручной просмотр.
- **Литейная машина с обратной связью по рентгену:** патент описывает автоматическую подстройку параметров литья по дефектам, найденным рентгеном в реальном времени, с управлением несколькими машинами одновременно.
- **Научные группы КНР:** модель для малоконтрастных дефектов на алюминиевых колесах, 39 FPS; метод повышения контраста Retinex + глубокое обучение для рентгенограмм алюминиевых отливок, рост точности на 20,08 %.

## 6. Капиллярный, радиографический, ультразвуковой контроль

| | Капиллярный (PT) | Радиографический (RT, рентген) | Ультразвуковой (UT) |
|---|---|---|---|
| Что находит | только дефекты, **выходящие на поверхность** (трещины, поры) | **внутренние** объёмные дефекты: пористость, раковины, включения; трещины, если ориентированы вдоль луча | внутренние плоскостные дефекты: расслоения, плёны, трещины |
| Принцип | проникающая жидкость + проявитель | просвечивание, регистрация ослабления излучения | отражение ультразвука от дефекта |
| Скорость | медленно, ручные операции | быстро в 2D inline; КТ медленнее | быстро, хорошо для слитков/заготовок |
| Автоматизация по изображению | ограничена (визуальный осмотр) | **высокая**, готовая картинка для нейросети | сигнал (A/B/C-скан), своя обработка |
| Минусы | только поверхность, химия, ручной труд | защита от излучения, дорогое оборудование, плохо видны плоские дефекты поперёк луча | нужен контакт/иммерсия, сложно на сложной геометрии |

**Позиция проекта:** ПО Defect Vision QA не заменяет метод, а автоматизирует **расшифровку изображения** (в первую очередь радиографического).

## 7. На каких этапах производства можно автоматизировать контроль качества

Типичный путь слитка: *плавка → обработка расплава → литьё (ДЛ) → гомогенизация → резка → контроль → упаковка/отгрузка*.

| Этап | Что контролируется | Что можно автоматизировать | Подходит для проекта |
|---|---|---|---|
| Приготовление сплава | состав, водород | спектрометрия, анализ водорода (не зрение) | нет |
| Литьё | поверхность слитка, стабильность процесса | камера на поверхность + обратная связь на литьё | частично |
| После литья и резки | макро/микроструктура образцов | нейросетевой анализ микроструктуры (уже делает предприятие) | аналог, конкуренция с внутренней разработкой |
| Контроль внутренних дефектов | пористость, включения, плёнки | **рентген образцов/сечений + детекция нейросетью**; ультразвук для заготовок | **основной кейс MVP** |
| Финальный осмотр | поверхность, геометрия, маркировка | машинное зрение на конвейере | расширение |
| Отгрузка/рекламации | возвраты | аналитика связи дефектов и рекламаций | будущее |

**Что берём в MVP:** этап «контроль внутренних дефектов», 1 проекция, детекция пор, трещин и включений, на синтетике. **Дальше:** реальные снимки, затем ранжирование по классам допусков.
